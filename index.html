Marscolony

A heavy Euro board game (Vital Lacerda's On Mars) rebuilt for the browser so my friends and I can play it on phones, tablets or one shared screen. Every move is checked by a rules engine, and a bot can take any seat.

  • Rules engine in pure Python that runs in the browser through Pyodide, so there is no game server to pay for.
  • Online play through a Cloudflare Worker and a D1 move store, with undo, live leaderboard and Mission tracker.
  • A bot tuned by a scorer that plays batches of full games to check the rules and measure its strength.

How it runs

Rules engine

Pure Python with no I/O. Immutable state, a typed action log, and a seeded RNG, so every game can be replayed exactly.

→

Browser (Pyodide)

The same engine runs on each player's device. The page only shows the legal moves the engine allows.

→

Cloudflare Worker + D1

Stores each game's moves. Concurrent moves are ordered by log sequence, and snapshots are taken at moves that can't be undone.
